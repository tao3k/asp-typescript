#+title: ASP TypeScript Native Syntax Playbook

* Role

Use the TypeScript provider as the native-syntax authority for TypeScript and
JavaScript source.  All public discovery goes through one command:

#+begin_src sh
asp search playbook --language typescript --rg -n -e '<question>' . --tantivy 'title:<question>^2 OR body:<question>'
#+end_src

The Runtime composes ripgrep acquisition, TypeScript native-syntax projection,
resident Tantivy ranking, and ASP Python Graph correlation.  These stages are
not separate agent-facing commands.

* Intent selection

#+begin_src sh
asp search playbook --language typescript \
  --rg -n -e OrderStatus src test \
  --tantivy term OrderStatus

asp search playbook --language typescript \
  --rg -n -e findOrderStatus src test \
  --tantivy term findOrderStatus
#+end_src

A known owner path can narrow the native ripgrep block without replacing
native-syntax evidence with a path-only result.

* Receipt admission

Admit only a completed version-1 playbook receipt whose native-syntax stage
contains owner content digests, canonical selectors, proper byte ranges,
nonempty query keys, and owner-bound relations.  The projected owner set must
equal the decision owner set.  Partial or cross-generation evidence is a typed
terminal, never permission to dump source.

* Exact materialization

#+begin_src sh
asp query playbook --language typescript --selector '<typescript-selector>' \
  --projection source --workspace .
#+end_src

Use =callable-skeleton= when only a callable outline is required.  Edit the
selected owner and route TypeScript tests, checks, formatting, and builds to
ASP Testing while preserving the playbook generation and selector identities.
